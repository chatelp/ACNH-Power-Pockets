# ACNH Power Pockets - item glyphs: which small picture goes with each item.
# Pictures live in item_glyphs.png. Copy both files to sdmc:/switch/acnh_power_pockets/
# next to items.txt. Edit freely; the app reads them at launch.
#
# item_glyphs.png has one 24x24 cell per glyph (x = index * 24) on 3 rows:
#   y 0   full color, used when the item has no known color
#   y 24  tint mask (white + gray): draw it with SDL_SetTextureColorMod(color)
#   y 48  outlines and details, drawn over the tinted mask
#
# Lines:
#   glyph <index> <name> [tint] [single]
#                                 glyph table; "tint" = the glyph can take the item color,
#                                 "single" = items of this kind never stack in the game: the app
#                                 shows them as 1/slot and never asks for a quantity (the count
#                                 field of such an item is its variant). nonstackable.txt can
#                                 still add or remove single items one by one.
#   color <RRGGBB> <name>         color vocabulary, matched as whole words
#   <glyph name> <rule>           which items use the glyph
#
# Rule forms (case-insensitive, same spirit as nonstackable.txt):
#   golden axe       exact item name, as in items.txt
#   ~wand            the name contains "wand"
#   $dress           the base name ends with the word "dress" (preceded by a space,
#                    a hyphen or nothing). The base name is the name without its
#                    trailing " (variant)" and any " with ..." part:
#                    "frilly dress (Pink)" -> "frilly dress", "curry with rice" -> "curry".
#   0x16DB           one item id
#   0x08A7-0x08EC    an inclusive id range
#   *                every item (only useful as the first, default rule)
# Rules apply from top to bottom and the LAST matching rule wins: broad rules
# first, fixes last. An item that no rule matches uses glyph 0 (unknown, "?").
#
# Item color (tint glyphs only): the first color word of the (variant), longest
# name first, else of the base name ("white-tulip stems", "red umbrella").
# No color found: the full-color row is used.
#
# Generated and checked by tools/make_item_glyphs.py (--coverage).
